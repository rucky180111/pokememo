# 選出評価 v3：実装と検証の対応

参照元は利用者の「ポケメモ 選出評価システム 統合仕様書」版3（2026-10-27）。ここでは実装した範囲と、仕様上まだ未評価である範囲を記録する。採点基準を新たに定義する文書ではない。

## 入力と保存

構築の `selectionAssessment` に schemaVersion / dataVersion / updatedAt / source / rolesCsv / risksCsv / openingCsv / rules を保存する。既存の構築・単体対戦・構築全対戦のJSON書き出しはこの値を保持する。対戦中は自軍の型スナップショット `battle.my` を用い、同じ名前の構築を後で変更しても対戦の型を差し替えない。対戦作成時の評価データもスナップショットとして保持し、画面に版・根拠・更新日時を表示する。選出の適用時は推薦の版・点数・先発も記録する。旧対戦は評価データがない場合に構築の現在版を参照し、適用時に保存する。単体対戦の書き出しにも含まれる。

CSV/TSVは引用符・改行・BOMを扱う既存のreadTableを共用。ファイルはUTF-8、文字化け時にShift-JISも読む。編集欄の全データを検証してから単一の構築更新で保存する。エラーのある行を部分採用しない。

候補名は自分の構築へ一意に解決する。明示的なメガ形態が持ち物による予定形態と異なる場合はエラー。条件は既存のparseCond/condMatchesを使用し、`A+-B`等はエラー。メモ・理由に書かれた天候や前提を計算条件と解釈しない。

## 全列挙と静的採点（仕様1〜3、8〜9章）

石を持つ2体＋一般4体で、0〜1石持ちは16組・固定先発込み48候補、ちょうど1石持ちは12組・36候補。控えの順番は同一視する。石は実際の種族・持ち物による進化先から判定する。

役割は成立した行だけを対象にし、対応危険を引いた適性の最大値を取る。同一危険ID・対象・場面の重複は最大値、別IDは加算、補正適性は0〜100。不足減点は各役割に1回。選出危険と先発危険を分け、対応危険を再度引かない。危険の自分条件は選出3体へ適用する。

順位は静的点降順、不足役割の重要度合計昇順、先発危険昇順、先発と控えの自軍登録順。同じCSV行の並べ替えで得点・担当・順位が変わらない。hardRulesの禁止・必須を満たさない候補は除外し、候補ゼロなら理由を表示する。制約の自動解除・自動補完を行わない。

上位3と全候補を切り替えられ、役割別の担当・代替・補正・不足・役割集中、危険の理由、予定メガ、1位と2位の点差を表示する。旧優先順位は比較表示に限定し、正解ラベルや重みへ変換しない。

## 手動ケース参照（仕様4〜8、10、13章）

全48候補それぞれの自軍先発を固定し、相手6先発の288マスを保持する。相手先発の重みはデフォルトが均等な仮定。`openingEvaluation.leadWeights` を種族名/ID→0以上の重みとして設定した場合は正規化し、`leadWeightsSource` が `manual` / `measured` のどちらかであることを必須にする。全0・現在の相手6体に対する全0はエラー。使用率の数値をそのまま先発率として使わない。

ケースは相手条件・自分の選出条件・自分の固定先発・相手先発・選出された交代先で絞る。異なる型・相手初手・自分の初手をまとめて最適化しない。攻撃された場合、積まれた場合、初手後の状態、次ターン、残る不安、根拠をケースごとに表示する。

仕様の見本列だけでは検証の有無を判別できないため、任意の `検証済み` 列を加えた。`未評価` 以外を表示するケースには `true` と根拠を必須とする。任意の `自分条件` 列は同じ既存文法で選出3体へ適用する。元の未評価テンプレートは変更せず読み込める。

検証済みケースがあっても、全ての型・裏・初手・相手の交代を網羅したと自動認定しない。未登録ケースは安全ではなく未評価。見本の「剣舞後」「メガ前の水弱点」「スケイルショット」は説明を保持し、単発のダメージ関数で実行済みの対戦結果に置き換えない。

## 未評価の範囲を明示する

この実装は静的全列挙＋手動ケース参照。2〜3完全ターンの状態遷移探索、合法な相手セットと見えない裏の確率モデル、公開観測に依存する共通継続方策の最適化、数値のQ・DownsideRiskの算出は行わない。係数だけが設定されても `totalScore` はnullとし、全候補を「静的順位」と表示する。仮の係数・独自の状態採点・勝率換算を付けない。

仕様第7章の総合式を有効にするには、Qの尺度、下振れ定義、共通行動を守った数値モデル、α/β/λとその版が必要。現時点で「交代後まで評価済み」「総合最適」「実戦勝率最大」とは表示しない。
