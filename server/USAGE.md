# ゲーム内バトルデータの使用率を取り込む (usage-scrape.mjs を作る)

同期サーバーは、`server/usage-scrape.mjs` があれば1日1回それを呼び、結果をアプリ用の使用率データに変換して
`/api/usage` で配ります (アプリは自動で取り込みます)。サイトの形はこちらからは見えないので、このファイルだけラズパイ側で作ります。

## 作るもの

`server/usage-scrape.mjs` に、次の関数を1つ書きます (Node 24、依存パッケージなし、fetch は引数で渡されます)。

```js
export async function scrape(fetch) {
  return {
    season: 'M-6',                 // シーズン名
    rule: 'single',                // シングルだけ
    updatedAt: '2026-10-13T11:00:00+09:00',  // サイトのデータの更新日時 (分からなければ取得日時)
    source: 'バトルデータベース チャンピオンズ',
    pokemon: [
      {
        name: 'ガブリアス',        // 日本語名。フォルムは「ゾロアーク(ヒスイ)」「イダイトウ(メス)」、メガは「メガボーマンダ」の形が理想 (多少違っても近い名前で照合します)
        rank: 1,                  // 使用率の順位
        usage: 24.2,              // 使用率の % (サイトに無ければ書かない)
        moves: [['じしん', 99.5], ['スケイルショット', 49.1]],          // 技の採用率 % (サイトにあるだけ)
        items: [['きあいのタスキ', 40.2], ['ガブリアスナイトZ', 20.1]], // 持ち物 (メガストーンも含めてよい)
        abilities: [['さめはだ', 99.3]],
        natures: [['ようき', 50.9], ['いじっぱり', 30.0]],
        teammates: [['アシレーヌ', 30.1]],                             // 同じチームのポケモン (あれば)
        spreads: [['ようき', [2, 32, 0, 0, 0, 32], 12.3]],              // 能力ポイントの配分 (あれば。H A B C D S)
      },
    ],
  };
}
```

- 割合は 0〜100 の % のまま入れてください (変換で 0〜1 にします)
- 足りない項目 (初手率・能力ポイントの配分など) は、同梱の Showdown の集計で補います
- 30体以上取れないときは失敗扱いになり、前のデータを使い続けます

## 取得先とマナー

- 取得先の例: バトルデータベース チャンピオンズ (https://champs.pokedb.tokyo/) のシングル・最新シーズン
- 取りに行く前に、そのサイトの robots.txt と利用規約を確認し、許されている範囲で取得してください
- 1日1回だけ、ページの間に1秒以上あけて、User-Agent に連絡先がわかる名前を入れてください
- 公式の API や一覧 JSON があるなら、HTML よりそちらを使ってください

## 試し方

```sh
cd ~/pokememo/server
docker compose up -d --build                         # 作ったファイルを取り込んで作り直す
docker compose exec pokememo-sync node usage-update.mjs   # すぐ取り込む (結果と警告が出ます)
curl -s -H "Authorization: Bearer <SYNC_KEY>" http://127.0.0.1:8787/api/usage/status
```

警告の「名前を対応づけられなかったもの」が多いときは、名前の書き方 (フォルムの表記など) を合わせてください。
