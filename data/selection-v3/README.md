# 選出評価 v3 のデータ

基準は利用者が2026-10-27に提示した「ポケメモ 選出評価システム 統合仕様書」版3。本ディレクトリは第11章の説明用見本であり、完成した評価データ・実戦勝率・正解選出ではない。

- `roles-example.csv`: 役割ごとの最大適性を採点する仮値。
- `risks-example.csv`: 選出・先発・対応を区別した仮減点。
- `rules.json`: メガ石持ち最大1体、空のhardRules、対応危険のリンク。
- `opening-cases-template.csv`: 未評価の記入例。積み・未メガ交代・連続技の注意を含むが、検証済み結果ではない。

アプリの構築「選出評価」から複数ファイルを読み込み、検証結果を確認してまとめて保存できる。構築に存在しない候補があれば行番号付きで保存を止める。上位3候補と全候補は静的順位として表示する。

既知の手動ケースを入れる場合は、仕様の11列に `検証済み` 列を追加し `true` と根拠を指定する。未評価行はこの列が不要。任意の `自分条件` 列で選出3体を限定できる。相手先発・自分先発・交代先・型ID・相手行動の別を保持し、各ケースを別の行で表示する。攻撃分岐と積み分岐にそれぞれ都合のよい行動を選び平均する機能はない。

手動ケースの参照は全分岐を解く対戦AIではない。未登録の型・裏・行動・相手交代は未評価。静的CSVと記入例から安全な引き先や勝率を推測しない。
